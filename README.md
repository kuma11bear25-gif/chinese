# 中国語単語クイズ

ブラウザだけで動く中国語単語学習アプリです（ビルド不要）。

## 機能
- **レベル選択**：初級（HSK1〜3程度）／上級（HSK5〜6程度）
- **品詞別カテゴリー**：名詞・動詞・形容詞・副詞（各レベル各50語、計400語）＋「すべて」
- **3つの出題モード**
  - 単語 → 意味
  - 音声 → 意味（ブラウザの音声合成で中国語を読み上げ）
  - 意味 → 単語
- **正解回数カウント**：単語ごとの正解回数・回答回数をブラウザ（localStorage）に保存
  - 単語一覧画面で確認・リセット可能
  - 「正解回数の少ない単語を優先」オプション
- 結果画面から「間違えた単語だけ」を再挑戦
- キーボード操作：`1`〜`4` で選択、`Enter` で次へ

## 使い方
`index.html` をブラウザで開くだけです。GitHub Pages で公開することもできます。

> 音声モードは端末に中国語（zh-CN）の音声が入っている必要があります。
> iPhone/Mac・Android・Windows の Chrome/Edge/Safari なら通常そのまま使えます。

## 単語の追加
初級は `words.js`、上級は `words_adv.js` の各品詞の `list` に `["漢字", "ピンイン", "意味"]` を追加してください。
新しい品詞（量詞・介詞など）も同じ形式でキーを足せば自動でメニューに出ます。
