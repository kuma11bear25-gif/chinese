# 中国語単語クイズ

ブラウザだけで動く中国語単語学習アプリです（ビルド不要）。

## 機能
- **HSK級別**：HSK1〜6級（旧HSK 2.0 の級分け）
- **HSK各級の全単語を収録**（計4991語）：1級150語・2級147語・3級298語・4級598語・5級1298語・6級2500語
- **品詞別カテゴリー**：名詞・動詞・形容詞・副詞・その他・熟語＋「すべて」
  - 語数の少ない代詞・数詞・量詞・介詞・接続詞・助詞などは「その他」にまとめています
  - 熟語は各級10個（1〜3級は日常の決まり文句、4〜6級は成語。`idioms.js`）
- **2つの出題形式**（どちらもブラウザの音声合成で中国語を読み上げ、意味を4択で選ぶ）
  - 単語の聞き取り：選択肢は発音の似た単語から出題
  - フレーズの聞き取り：各級の単語を2〜3語組み合わせた言い回し（各級15問。`phrases.js`）
    - 選択肢はフレーズごとに用意した「発音の似たフレーズ」3つ（例：喝茶 hē chá → 很差 hěn chà／和他 hé tā／黑车 hēi chē）
- **正解回数カウント**：単語ごとの正解回数・回答回数をブラウザ（localStorage）に保存
  - 単語一覧画面で確認・リセット可能
  - 「正解回数の少ない単語を優先」オプション
- 結果画面から「間違えた単語だけ」を再挑戦
- 選択肢に「わからない」ボタン（不正解扱いで正解を表示）
- キーボード操作：`1`〜`4` で選択、`5` でわからない、`Enter` で次へ

## 使い方
`index.html` をブラウザで開くだけです。GitHub Pages で公開することもできます。

> 音声モードは端末に中国語（zh-CN）の音声が入っている必要があります。
> iPhone/Mac・Android・Windows の Chrome/Edge/Safari なら通常そのまま使えます。

## 単語の追加
フレーズは `phrases.js` の `HSK_PHRASES[級]` に `["中国語", "ピンイン", "意味", "使っている単語", [ダミー×3]]` を追加してください（ダミーは `["中国語", "ピンイン", "意味"]`。発音の似たものを3つ）。
単語は `words.js` の `HSK_WORDS[級][品詞]` に `["漢字", "ピンイン", "意味"]` を追加してください。
新しい品詞（量詞・介詞など）は `CATEGORY_LABELS` と各級にキーを足せば自動でメニューに出ます。

## データの出典
級・品詞・ピンインは [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary)（MIT License）を元にしています。日本語訳は独自に付けたものです。

スマホなどで古いファイルが残らないよう、`index.html` で読み込む CSS・JS には `?v=日付` の版番号を付けています。
`app.js` などを変更したら、`index.html` の `?v=` の値もまとめて変更してください。
