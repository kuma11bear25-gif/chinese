# 中国語単語クイズ

ブラウザだけで動く中国語単語学習アプリです（ビルド不要）。

## 機能
- **HSK級別**：HSK1〜6級（旧HSK 2.0 の級分け）
- **品詞別カテゴリー**：名詞・動詞・形容詞・副詞（各級・各品詞 最大50語、計974語）＋「すべて」
  - HSK1・2級は試験の語彙自体が少ないため、形容詞・副詞などは50語未満です
- **3つの出題モード**
  - 単語 → 意味
  - 音声 → 意味（ブラウザの音声合成で中国語を読み上げ。選択肢は発音の似た単語から出題）
  - 意味 → 単語
- **正解回数カウント**：単語ごとの正解回数・回答回数をブラウザ（localStorage）に保存
  - 単語一覧画面で確認・リセット可能
  - 「正解回数の少ない単語を優先」オプション
- 結果画面から「間違えた単語だけ」を再挑戦
- キーボード操作：`1`〜`4` で選択、`Enter` で次へ

## 使い方
`index.html` をブラウザで開くだけです。GitHub Pages で公開することもできます。

> 音声モードは端末に中国語（zh-CN）の音声が入っている必要があります。
> iPhone/Mac・Android・Windows の Chrome/Edge/Safari なら通常そのまま使えます。

## 単語の追加
`words.js` の `HSK_WORDS[級][品詞]` に `["漢字", "ピンイン", "意味"]` を追加してください。
新しい品詞（量詞・介詞など）は `CATEGORY_LABELS` と各級にキーを足せば自動でメニューに出ます。
